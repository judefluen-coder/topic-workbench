## 测试发现并修复的问题

### P1：测试会污染正式数据库

项目改用 `TOPIC_WORKBENCH_DB_PATH` 后，部分继承测试仍设置旧变量 `TECH_PR_DB_PATH`。在存在 `.env` 的机器上，测试会误用正式 `storage/app.db`，导致用例相互污染并可能写入用户数据。

修复：全部后端测试切换到新环境变量，上传、导出和临时目录也使用独立测试路径。清理本轮生成数据后复测，正式数据库保持 1 个默认主题、0 条视频和 0 个任务。

### P1：真实文件上传会因时间戳解析崩溃

上传文件名把包含字母 `T` 的 ISO 时间直接转为整数，真实 multipart 上传触发 `ValueError`。

修复：改为 UTC `strftime` 时间戳并增加 UUID 后缀；新增真实 multipart 上传回归测试，避免同秒文件名冲突。

### P1：YouTube 无 API Key 回退搜索容易错过日期窗口

yt-dlp 回退搜索此前只按相关性取前三条，常返回较老视频，随后全部被日期过滤。

修复：搜索查询加入 YouTube `after`/`before` 日期条件；真实复测在指定窗口新增 2 条视频。

### P2：多词关键词和 B站默认词覆盖不足

多词关键词要求连续匹配，标题中词序或间隔变化时会漏判；B站中文搜索对 `人工智能 访谈`结果不稳定。

修复：支持多词 token 非连续匹配，默认主题增加 `AI 访谈`并只对未修改的旧默认主题做安全迁移。真实 B站复测新增 3 条视频。

## 剩余风险与说明

- YouTube API Key 未配置，本轮验证的是 OpenCLI/yt-dlp 回退模式；覆盖范围不等同于官方 Data API 的完整结果。
- 外部平台搜索结果会随地区、登录态、风控和平台页面变化而波动。
- 为遵守素材授权边界，下载测试使用本机生成并通过 localhost 提供的授权视频；下载引擎、任务状态和文件落盘均为真实链路。
- FastAPI 仍有 `on_event` 与 TestClient/httpx 的弃用警告，不影响当前功能，后续可迁移到 lifespan API。
- Ollama 未安装，仅影响可选本地 AI 增强，不阻塞抓取、下载、字幕导入和粗剪导出。
